# food-picture-01 — Steaming Gourmet Ramen

Entry for make.fun's food-picture-01: "Make the best-looking food picture."

The image is a steaming bowl of gourmet ramen — rich golden broth with
glistening oil droplets and chili-oil swirls, jammy soft eggs, caramelized
chashu pork, fresh green onions, nori and bamboo shoots, chopsticks resting
on the rim, shot in warm natural light on a dark rustic table.

The program (`main.ts`, Node 22, standard library only) copies `entry.png`
to `/output/entry.png`. The file is a JPEG (200 KB, 1024x683) named
`entry.png`, which the rules allow (format is told apart by first bytes).
